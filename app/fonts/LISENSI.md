# Lisensi huruf

Dua keluarga huruf disertakan langsung di dalam repositori ini, bukan dipanggil
dari server luar. Alasannya dua: halaman tampil benar walau server font sedang
bermasalah, dan alamat pengunjung tidak ikut terkirim ke pihak ketiga.

| Berkas | Huruf | Lisensi |
| --- | --- | --- |
| `PlusJakartaSans-Variable-latin.woff2` | Plus Jakarta Sans | SIL Open Font License 1.1 |
| `InstrumentSerif-Regular-latin.woff2` | Instrument Serif | SIL Open Font License 1.1 |
| `InstrumentSerif-Italic-latin.woff2` | Instrument Serif Italic | SIL Open Font License 1.1 |

SIL Open Font License 1.1 mengizinkan huruf ini dipakai, disalin, diubah, dan
disebarkan ulang, termasuk untuk keperluan komersial, selama:

1. huruf itu tidak dijual sendirian sebagai barang dagangan,
2. keterangan hak cipta dan lisensinya ikut disertakan, seperti berkas ini, dan
3. hasil ubahannya tidak memakai nama huruf aslinya.

Ketiganya dipenuhi di sini. Berkas `.woff2` di atas adalah potongan huruf latin
dari rilis resmi, tanpa perubahan bentuk apa pun.

Teks lengkap lisensinya bisa dibaca di <https://openfontlicense.org>.

Kalau suatu saat kamu mengganti hurufnya, ganti juga baris di tabel ini. Berkas
huruf yang tidak jelas lisensinya sebaiknya tidak dipakai di situs yang bisa
diakses umum.
